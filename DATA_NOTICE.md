# Data notice

This repository contains short audio excerpts downloaded from public YouTube
URLs for an internal Darija speech-to-text benchmark. The repository does not
claim ownership of those recordings or grant a new license for them.

- Source URLs and processing status are recorded in `selected_videos.csv`.
- Audio files are included because the repository is private and the project
  owner explicitly requested a reproducible snapshot.
- Do not make the repository public or redistribute the audio without first
  verifying the rights, platform terms, consent, and retention requirements
  applicable to every source.
- Remove `audio/*.mp3` before creating a public release unless redistribution
  rights have been confirmed.

Mistral API credentials, `.env` files, virtual environments, caches, and other
secrets are intentionally excluded.
